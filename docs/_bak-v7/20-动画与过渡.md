# 20 动画与过渡

> 本册回答：**动画改的是哪一相、成本差多少、值存在哪、什么类型不能动、后台页为什么必须停。**
> 来源：v6 第 13 轮（D-35）。v7 第一版只有 `05` §9.4 的三档成本表，
> 没有"值存哪""什么类型不能动""offstage 为什么必须暂停"——那三条才是会踩的坑。

---

## 0. 一句话

**动画不是"一种脏"，它改哪一相就标哪种脏。**

这句话解决了 v7 第一版留下的全部问题：三档成本表只说"有快有慢"，
没说"慢的那档是怎么被选中的"。答案是：**由被改的字段决定，不由动画本身决定**。

---

## 1. 字段 → 相 → 脏位

| 字段 | 相 | 每帧动作 | 脏位 | 相对成本 |
|---|---|---|---|---|
| `translate` / `scale` / `rotate` / `opacity` | 合成 | 只改矩阵 | `DIRTY_COMPOSE` | 1× |
| `background` / `radius` / `shadow` / 文字内容 | 绘制 | 重录该节点段 + 光栅"旧 ∪ 新 bounds" | `DIRTY_PAINT` | ~20× |
| `padding` / `gap` / `size` / `flex` | 布局 | 重排子树 + 牵连兄弟 | `DIRTY_LAYOUT` | ~100× |

★ 这张表是**唯一**的判据来源。想知道一个动画贵不贵，看它改哪个字段，不用问框架。

### 1.1 两条由此推出的硬规则

★★ **规则一：位移必须用 `->translate()`，不能用 `->position()`。**
后者是布局属性 ⇒ 每帧重排；前者只改矩阵。**用错一个修饰器，成本差一个数量级。**

★★ **规则二：能用绘制相表达的动画，不要用布局属性表达。**
"高度从 0 展开"是布局相；换成"淡入 + 内容直接出现"就落到绘制相，便宜 20 倍。
这不是妥协——**用户看到的是"出现了"，不是"长出来了"。**

## 2. 动画值存在哪

三选一，只有第三个对：

| 存哪 | 每帧发生什么 | 判据 |
|---|---|---|
| 进 `Cell` | 所有读者重算 ⇒ **重建整棵子树** | 最贵，且把"过程"污染成"状态" |
| 进节点 config（声明字段） | `from` 无处安放；目标中途变化只能从头补间 ⇒ **抽搐** | 错 |
| **进 `node.local`** | 推进直接标脏，不经相等性比较 | ✅ |

★★ 合成一句：**`Cell` 存意图，`node.local` 存过程。**

- `config` 里存**目标值**（"我要到 100%"）；
- `local` 里存**当前插值**（"现在是 37.2%"）；
- 推进 = 写 `local` + 标脏，**不写回状态图**。

★ 这条同时解释了为什么"隐式动画从当前插值开始"能成立（§4）：
当前值就在 `local` 里，随时可读。

★ 推论：`node.local` **不进语义树、不进快照**。它是渲染过程，不是应用状态。

## 3. Tween：按静态类型在构造期绑定

```php
// ✅ 三个具体类，构造期就绑定插值函数
final class FloatTween { public function lerp(float $a, float $b, float $t): float; }
final class ColorTween { public function lerp(int $a, int $b, float $t): int; }
final class IntTween   { public function lerp(int $a, int $b, float $t): int; }

// ❌ 绝不这样
interface Tween { public function lerp(mixed $a, mixed $b, float $t): mixed; }
```

★ **为什么禁止 `mixed`**：`mixed` 在 AOT 下是 `Var` ⇒ **每字段每帧一次装箱**。
一个 500 节点的动画，一帧就是 500 次装箱，直接吃掉预算。

★ 分派方式与 L3 一致：`switch ($node->kind)` 选具体 Tween，**不走虚方法**。

### 3.1 颜色必须走 OKLab

| 插值空间 | 红 → 绿 的中间色 |
|---|---|
| sRGB 直接插值 | **经过灰暗的土黄色**（视觉上像掉色） |
| **OKLab** | 明亮的过渡色（符合感知） |

★ 这不是"更好看"，是**正确**：sRGB 是非线性感知编码，直接线性插值在感知上不等距。
用户看到的"颜色发脏"就是这个原因。

### 3.2 不支持的类型要报错，不静默降级

| 类型 | 支持？ |
|---|---|
| `float` / `int` / `Color` / `Offset` / `Size` / `Rect` | ✓ |
| `enum` / `string` / `bool` / 节点引用 | ✗ ⇒ **`E-ANIM-TYPE`** |

★★ **不支持就报错，绝不静默降级成"瞬间跳变"**。
静默降级的后果是"这个动画在某些控件上不生效"，而没人知道为什么——
错误消息至少能指到字段名。

## 4. 三形态，各有各的纪律

| 形态 | 写法 | 用于 | 纪律 |
|---|---|---|---|
| **隐式** | `->animate(200, curve: ...)` | 字段值变化时自动补间 | **从当前插值开始**（不是从上次目标） |
| **显式** | `Controller` + `forward/reverse` | 需要控制进度、可中断 | 完成/取消都必须退订 |
| **过渡** | `transition: slideUp` | 页面/浮层进出 | 标 P3（首版不做） |

★★ **隐式动画必须从当前插值开始**：
从"上次的目标"开始，会在动画中途改目标时出现**抽搐**（先跳回旧起点再走）。
这就是 §2 把当前值放在 `local` 里的直接回报。

★★ **完成必须退订 Clock**：
没退订 ⇒ `wantsFrame()` 永远为 true ⇒ 按需帧循环退化成 60fps 常转，**空闲 CPU 从 0 变满**。
判据在 [09](09-帧与异步.md) §5：**帧间变化像素数连续两帧为 0** ⇒ 动画已结束但还在请求帧。

---

## 5. `offstage` 必须暂停推进

★★ 这是 v7 第一版完全没有的一条，也是"切后台"类 bug 的根源：

```
页面被盖住 ⇒ offstage（仍在 settle，见 [16](16-应用分层.md) §3）
          ⇒ 但它的动画进度还在
          ⇒ 若不暂停推进：一个看不见的页面撑起整个按需帧循环
          ⇒ 空闲 CPU 从 0 变满，风扇转起来
```

★ **`offstage` 与"完成退订"是同一个洞的两个入口**：
- 完成没退订 ⇒ 单页空转；
- offstage 没暂停 ⇒ 后台页空转。

两者都必须覆盖，且**都要有可测判据**：**切后台 60s，唤醒次数必须为 0**。

★ 恢复时**不重新开始**：进度按"暂停那一刻 + 经过时间"继续（或按策略直接跳到终点），
但不能"从 0 重播"——那会让用户觉得页面刚加载。

## 6. 弹簧与打断

| 规则 | 理由 |
|---|---|
| 弹簧用**固定 16.667ms 子步**积分 | 保证确定性 ⇒ golden 可复现；与真实帧率解耦 |
| 打断时**从当前值出发**（不是从起点） | 否则"按停再走"会跳 |
| 弹簧**保留速度**（Tween 归零） | 归零后像"被按停"，不像"接住" |
| 振荡超过 3 个周期 ⇒ `W-SPRING-OSCILLATE` | 参数配错了，要能统计 |

★ "固定子步"这条与 [09](09-帧与异步.md) §2 的"动画相位 = f(帧时间戳)"是同一族纪律：
**能用纯函数表达的，不要用累加**。累加在掉帧时漂移，纯函数不会。

---

## 7. 时长与无障碍

| 规则 | 说明 |
|---|---|
| 时长一律**整数毫秒**：`->animate(200, ...)` | PHP 没有时长字面量；不引 `Duration` 对象（多一层装箱） |
| `reduceMotion` 开启 ⇒ **时长归零**（不是"缩短"） | 归零后仍是同一条代码路径，只是瞬间完成 |
| 时长上限 400ms（超出要显式声明） | 超过 400ms 的动画在桌面应用里会显得迟钝 |

★ `reduceMotion` 必须是**系统设置的读取**（平台能力），不是应用自己配的开关。

---

## 8. 反模式

| 反模式 | 症状 | 正解 |
|---|---|---|
| 用 `->position()` 做位移 | 每帧重排，卡 | `->translate()`（§1.1） |
| 用高度展开做"出现" | 布局相，贵 100 倍 | 淡入 + 内容直接出现（§1.1） |
| 动画值写进 `Cell` | 每帧重建子树 | `node.local`（§2） |
| `interface Tween { lerp(mixed) }` | 每字段每帧装箱 | 按静态类型分派（§3） |
| sRGB 插值颜色 | 中间色发脏 | OKLab（§3.1） |
| 不支持的字段静默跳变 | "这个动画不生效"，无人知道原因 | `E-ANIM-TYPE`（§3.2） |
| 完成后不退订 | 单页空转，空闲 CPU 不为 0 | 变化像素数为 0 即退订（§4） |
| offstage 不暂停 | 后台页撑起帧循环 | 暂停推进（§5） |
| 累加式推进 | 掉帧后相位漂移 | 纯函数 `f(时间戳)`（§6） |
