# 06 · 输入、手势与焦点

> 对应 design-v7 [07-输入与焦点](../design-v7/07-输入与焦点.md)。本文描述**实现**。

## 1. 一句话

输入归一化边界在平台壳：Win32 把原生消息翻译成 Drift 的 `InputEvent`，其余全走框架。手势用
**arena** 且 **Tap 必须居首**（指针 down 先注册 Tap 意向，其余手势后到再仲裁）；命中测试
**一次命中、三方消费**（事件路由 / 语义 / 光标形状只走一次树）；焦点链每帧重建；拖放/上下文菜单/
悬停/光标都是 Widget 上的**声明**，由 `FocusManager` 与命中链统一解析。

## 2. 手势 arena

- `GestureArena`（`src/Input/GestureArena.php:20`）：多手势竞争同一指针时仲裁。
- `GestureRecognizer`（`src/Input/GestureRecognizer.php:22`）：各手势识别器向 arena 申报意向。
- ★★★ **Tap 必须居首**：指针 down 先声明 Tap 意向，拖动/长按等后到再与 Tap 仲裁——否则拖到第 2 步
  就断（合成鼠标移动必须真挪物理光标，`PostMessage(WM_MOUSEMOVE)` 不挪光标 ⇒ 壳侧
  `TrackMouseEvent(TME_LEAVE)` 立刻回 `WM_MOUSELEAVE` ⇒ 手势收口；真机探针已加 `--cursor` 参数）。

### 2.1 点击链：`TapTracker`（"这一下是第几次点击"）

- `TapTracker`（`src/Input/TapTracker.php:40`）：**只有状态、没有时钟**。时间由
  `Application::dispatchInput()` 的第 2 参（壳给的 `Platform::now()`）注入，本类只回答"第几下"。
- `PointerEvent::$clickCount` + `isDoubleClick()`（`src/Input/PointerEvent.php:126`）：
  未标注恒 `1`（夹具与桥的异常路径不必关心它）；`isDoubleClick()` 判 `=== 2` 而非 `>= 2`。
- **为什么判据留在 PHP**：Win32 的 `CS_DBLCLKS` / `WM_LBUTTONDBLCLK` 会把
  **间隔 / 距离 / 按键 / 修饰键**四条规则搬进 C++，而 smoke 驱不动壳 ⇒ 这四条再也测不到。
  它们恰恰是"改一行就静默坏掉"的那类规则（双击进编辑、双击选词、三击选段都挂在上面）。
- 四条规则（与 Windows 语义对齐）：间隔 ≤ 500ms（`GetDoubleClickTime()` 默认）、
  单轴位移 ≤ 4px（`SM_CXDOUBLECLK` 默认）、同按键、修饰键全同（`Ctrl+点两次` 不许算双击）；
  另加两条断链：指针**离开客户区**、时间**倒退**（注入假钟 / 校时）。
- 只数**按下**：`Move` / `Up` 原样返回、不推进链（点击语义在按下那一刻就定了）。

## 3. 一次命中、三方消费

`RenderBox::hitTest()`（`src/Layout/RenderBox.php:169`，见 [03](03-布局与渲染盒.md) §5）返回最深命中盒；
调用方（输入路由 / 语义 / 光标形状）只走一次树各取所需——"命中一次、三方消费"是 §9.1 的核心契约。

## 4. 焦点链

- `FocusManager`（`src/App/FocusManager.php:40`）：每帧 `collect()`（`Application::frame()` 末段）重建
  焦点链；保留仍存在的焦点，幂等。
- Widget 声明焦点：`focusOrder(int)` / `skipFocus()`（`src/Widget/Traits/WidgetFocus.php:33` 起）；
  输入控件在**构造器**里 `markFocusable()`（`src/Widget/Traits/WidgetFocus.php:105`）。
  ★ 这里曾有第三个声明 `claimKeys(array)`（"焦点独占这些键，加速键让位"），2026-11-03 删除：
  它是逐键列举，列不全就是死键；键归谁改由**路由顺序**回答（焦点链先，加速键后）。
- **激活唯一入口**：`Application::activateFocusedWidget()`——键盘 Space/Enter 与指针按下都走它，
  控件自己不装点击监听器（与 `Button` / `Toggle` 同路，`src/Widget/ToggleBase.php:41` 注释）。

## 5. 光标 / 拖放 / 菜单 / 悬停 / 语义（都是声明）

全是 Widget 上的字段声明，命中链取**最深**者解析：
- 光标：`cursor(CursorShape)`（`src/Widget/Widget.php:242`）—— 不给控件开自绘光标的口子。
- 拖放：`draggable(Draggable)` / `dragTarget(DragTarget)`（`src/Widget/Drag/`）+ `DragController`（`src/App/DragController.php:31`）。
- 右键菜单：`contextMenu(ContextMenu)`（`src/Widget/Widget.php:315`），挂在子树上、命中链向上找最近声明者。
- 悬停：`hover(\Closure)`（`src/Widget/Widget.php:344`）—— 只在目标变化时派发（进/出各一次）。
- 语义：`semantics(Role, name, value, enabled)`（`src/Widget/Widget.php:378`）—— **字段赋值不是虚方法覆写**（虚方法去虚化会静默吞掉子类覆写 ⇒ 所有节点角色为空）；不声明 = 不进语义树。

## 6. 加速键（菜单/快捷键）

`AcceleratorTable`（`src/Input/AcceleratorTable.php:39`）：菜单项 / 快捷键声明的键和弦，命中时发命令
（走 [07](07-状态-订阅-命令.md) 的命令派发链）。`TextField` 用 `claimKeys()` 独占编辑键
（Ctrl+A/C/V/X/Z）不让加速键抢。
