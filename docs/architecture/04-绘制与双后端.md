# 04 · 绘制与双后端

## 1. 一句话

绘制是 `Canvas` 接口的扁平 op 流：节点 `paint($canvas)` 直接画，`canvas` 在画每个子盒前已
`translate` 到盒原点，所以 `paint` 内部以 (0,0) 为盒左上角。三个实现：**`RecordingCanvas`**（生产路径
录制 DisplayList）、**`SkiaCanvas`**（回放器，真实 Skia 后端）、**`RasterCanvas`**（纯 PHP 软光栅，无窗
可跑、可移植）。14 个 op 分 Core / Extended / Optional 三层。

## 2. `Canvas` 接口（14 方法，`src/Rendering/Canvas.php:29`）

| 方法 | 层 | 说明 |
|---|---|---|
| `save()` / `restore()` | 变换栈 | 只管偏移；与裁剪栈**两条独立栈**（W8 分别计深） |
| `translate(float,float)` | 变换 | 改 PHP 侧 offset，**从不调 Skia**——每个 draw 自己把偏移加进坐标 |
| `pushClip(Rect)` / `popClip()` | 裁剪栈 | 与 translate 互不干涉 |
| `drawRect(Rect, Paint, radius=0)` | Core | 直角/圆角 |
| `drawParagraph(Paragraph, Paint, x, y)` | Core | 文本；段里存 `Paragraph` **引用**，字形位图在**回放时**才产生 |
| `drawEllipse(Rect, Paint)` | Core | 外接矩形内切 |
| `drawLine(x1,y1,x2,y2, Paint)` | Core | 线段；Fill 风格报 `E-OP-UNSUPPORTED` |
| `drawPath(Path, Paint)` | Optional(P4) | 矢量路径填充/描边 |
| `drawImage(ImageHandle, ?src, dst)` | Optional(P4) | 图像缩放 |
| `drawShadow(Shadow)` | Optional(P4) | 阴影原语（替代 `RenderCard` 三层半透明矩形老路） |
| `pushLayer(opacity)` / `popLayer()` | 合成层 | 绘制栈第三条语义（不覆盖 W8 配平断言） |
| `pushClipPath(Path)` | Extended | 复用 `popClip()` 的裁剪栈（只裁形状不同） |
| `capabilities(): int` | — | 能力位掩码，CustomPaint 拿到画布时**查一次** |

★ 坐标纪律：`translate()` 只改 PHP 侧 `offsetX/offsetY`，**绝不调 Skia**——每个 draw 必须自己把
偏移加进坐标（`drawLine` 手加、`toDevice()` 走矩形）。新 op 照"几何走画布 translate()"写 ⇒ 落在画布
原点、被盒裁掉 ⇒ 真机**完全无墨**而解释器全过（P4 踩过）。

## 3. 三个实现

| 实现 | 文件 | 角色 |
|---|---|---|
| `RecordingCanvas` | `src/Rendering/RecordingCanvas.php:17` | 生产路径入口：录制 DisplayList，**返回 `ALL_MASK`**——能不能画由回放时画布裁决 |
| `SkiaCanvas` | `src/Rendering/SkiaCanvas.php:57` | 回放器：真 Skia 后端（C++ 桥 `php_drift_skia_*`） |
| `RasterCanvas` | `src/Rendering/RasterCanvas.php:29` | 纯 PHP 软光栅，无窗可跑、天生可移植、golden 的物质基础 |

★ 配套：`DisplayList`（`src/Rendering/DisplayList.php:23`，录制产物）、`Path`（`:24`，矢量路径
字节序列化）、`ImageHandle`（`:22`，RGBA 行优先字节串）、`CanvasCapabilities`（`:36`，能力位）、
`SurfaceProfile`（`:22`，段计时开关）、`GpuContext`（`:20`，接口留口未实现）。

### 3.1 阴影：三份实现收成一份（2026-10-25）

改写前阴影有**三份**手写实现：

- `Modifier::paintBehind()` —— 三层递减外扩（Card 用；`shadow` 是 `0..1` 浓度）；
- `RenderPopupPanel::paintContent()` —— 整盒垫一层 `alpha=48`（Popup / Modal / Menu /
  Select 用；`elevation` 是像素，且盒已按 `2×elevation` 留白）；
- `Canvas::drawShadow()` —— 真 mask blur（Optional，**零消费者**）。

现在收成 `ShadowPainter::tryPaint()`（`src/Rendering/ShadowPainter.php`）：有 `CAP_SHADOW`
就 `drawShadow`，否则返回 `false` 让调用方走**自己的**降级形状。

- **为什么降级不统一**：两处的"留白模型"相反 —— `paintBehind` 的盒**不含**阴影（画在盒外），
  `RenderPopupPanel` 的盒**含**投影留白（`2×elevation`，`performLayout()` 里已扣）。
  硬统一会破坏其中一个的布局假设。
- `paintBehind`：`blur = 3 + 9×shadow`、`dy = 1 + 3×shadow`、`alpha = 255×shadow`
  （`0.06` ⇒ blur 3.5px / dy 1.2px，与三层外扩 ±3px 同量级，不会突然"炸开"）。
- `RenderPopupPanel`：在 `panelRect()` 上 `blur = elevation`、`dy = 0.35×elevation`、
  `alpha = 48`（扩散 ≈1.5×elevation，落在预留的 `2×elevation` 内）。

★ 真机是 `SkiaCanvas`（`capabilities()` 含 `CAP_SHADOW`）⇒ 走真模糊；软光栅与
测试回放（Raster）⇒ 走各自降级。**两后端视觉差异是有意的**（`CAP_SHADOW` 本就是
Skia 独占的 Optional 位）。

## 4. 能力分级（D2，2026-10-20 采纳）

- **Core**：`drawRect` / `drawParagraph` / `drawEllipse` / `drawLine` —— 所有后端必须。
- **Extended**：渐变 / 虚线 / `pushClipPath` —— `RasterCanvas` 允许降级近似。
- **Optional**：`drawPath` / `drawImage` / `drawShadow` / `pushLayer` —— 仅 Skia 级。

`CustomPaint`（`src/Widget/CustomPaint.php`）在拿到画布时查一次 `capabilities()`，不在每次绘制时查。

## 5. 确定性：录制-回放（**测试与预览路径**）

> ★ **2026-10-25 校正**：本节原写"生产路径：录制 → 回放"，**不成立**。真机 `Frame`
> 是 `$box->paintComposed($canvas)` **直接画** —— `$canvas` 来自 `Win32SkiaSurface`
> （`SkiaCanvas`）或 `Win32RasterSurface`（`RasterCanvas`），**不经过 `DisplayList`**。
> 录制-回放只用于**测试夹具**（`RecordingSurface` / `SurfaceProbe`）、**预览**
> （`SvgSurface`，内部也是 Raster）与 golden 比对。

`RecordingCanvas` 把 `paint()` 的命令录进 `DisplayList`，再 `replay()` 到目标后端
（`RasterCanvas` 或 `SkiaCanvas`）。同一份命令两后端出相同像素（golden 可比性的基础）。

★★ **录制层的能力位必须等于回放端**（2026-10-25 契约变更）：原实现硬编码
`ALL_MASK`（"全录，回放裁决"），于是录制层会记下 Optional op（`drawShadow`），
回放端若是 Raster 就 `unsupportedOp` **响亮失败** —— 给阴影接第一个消费者时，
smoke 的 Card / 浮层段当场全崩（`rc=3`）。现在 `RecordingCanvas` 的能力**由构造参数
注入**，默认取 `RasterCanvas::supportedCapabilities()`（离屏回放的典型端）；要"全录"
的调用方显式传 `CanvasCapabilities::ALL_MASK`（`smoke` 有正反两条用例钉住）。
