# 08 · 控件面

> 对应 design-v7 [19-控件API语法](../design-v7/19-控件API语法.md) 与控件清单。本文描述**实现**。

## 1. 一句话

`src/Widget/` 共 **63** 个文件（+ `Drag/` 2 + `Menu/` 4），全部 fluent-first、Seal-on-Mount、
受控控件不自持状态。按"基类谱系 + 职责"分族，以下几族覆盖了真实控件全集。

## 2. 基类谱系

| 基类 | 文件 | 角色 |
|---|---|---|
| `Widget`（抽象根） | `src/Widget/Widget.php:25` | 全部控件的 sealed 描述基类 |
| `StatelessWidget` / `StatefulWidget` | `src/Widget/StatelessWidget.php:17` / `StatefulWidget.php:15` | 有无 State |
| `RenderBoxWidget`（抽象） | `src/Widget/RenderBoxWidget.php:21` | "有渲染盒的 Widget"基类 |
| `BoxWidget`（抽象） | `src/Widget/BoxWidget.php:25` | 盒样式（`BoxStyle` 值对象）基类：`Button`/`Card`/`PopupPanel`/`Dock`/`AppBar` |
| `Flex`（抽象） | `src/Widget/Flex.php:24` | 弹性布局：`Row`/`Column`/`Each` |
| `ToggleBase`（抽象） | `src/Widget/ToggleBase.php:46` | 开关三兄弟共用基座：`Checkbox`/`Radio`/`Toggle` |
| `CustomPainter`（抽象） | `src/Widget/CustomPainter.php:34` | 自定义绘制协议 |
| `Scrollable`（接口） | `src/Widget/Scrollable.php:20` | `ScrollView`/`LazyColumn` 的状态接口 |

## 3. 布局/组合族

`Row`（`src/Widget/Row.php:15`）/`Column`（`:15`）/`Each`（`:30`，带 Key 必填的列表）/ `Spacer`（`:17`）/
`Expanded`（`:18`，弹性项）/ `Padding`（`:19`）/`Center`（`:18`）/`SizedBox`（`:33`）/
`Offstage`（`:22`，跳过 layout ⇒ 尺寸 null ⇒ 命中测试自动 null）。

★ `SizedBox::height()` 小于子内容会触发 C6 Fatal（"画出的尺寸超出父容器给的可用空间"）把整帧拖垮——
定尺寸只给 `width`、高度让给内容是实测纪律（`src/Widget/SizedBox.php:56`）。

## 4. 盒式/容器族（`BoxWidget` 一脉）

`Button`（`src/Widget/Button.php:43`，`extends BoxWidget`）/ `NavButton`（`src/Widget/NavButton.php:18`）/
`Card`（`:39`）/ `PopupPanel`（`:28`）/ `Dock`（`:30`）/ `AppBar`（`:33`）。`BoxStyle` 是值对象，
盒样式经 `BuildContext` 取主题合并一次（[09](09-主题与语义.md)）。

## 5. 文本与表单

`Text`（`:29`，纯展示）/ `TextField`（`:48`）+ `TextFieldBox` + `TextFieldState`（`:37`，可编辑 +
IME + 选区）。

## 6. 开关（受控三兄弟）

`Checkbox` / `Radio` / `Toggle` 全部 `extends ToggleBase`——**不是继承关系链，是兄弟**，共用一个
`RenderToggle`（按 `int $kind` 分支）。受控：点击只回调 `onChanged(新值)`，值由应用 `setState` 改；
激活走 `Application::activateFocusedWidget()`（`src/Widget/ToggleBase.php:41`、`:133`）。

## 7. 滚动 / 虚拟化

- `ScrollView`（`:34`）+ `ScrollViewBox` + `ScrollViewState`（`:22`，`implements Scrollable`）：普通滚动。
- `LazyColumn`（`:48`）+ `LazyColumnState`（`:28`）：**虚拟化（M5）**——只构建可见窗口内的子项，
  万行列表实测 96ms→0.2ms（[12](12-工程与工具.md) 的 bench 数据）。

## 8. 自绘 / 模态 / 进度 / 错误边界

- `CustomPaint`（`:36`，`extends RenderBoxWidget`）+ `CustomPainter`（抽象）：用户画任意 op。
- `Modal`（`:41`）+ `ModalHost`（`:23`）/ `RenderModalHost`：模态层。
- `Progress`（`:36`）+ `ProgressBox` / `Spinner`（`:27`）+ `SpinnerBox` + `SpinnerState`
  （动画驱动：`SpinnerState::tickFrame()` 让 `wantsFrame()` 恒真 ⇒ 自转让，卸载自动停）。
- `ErrorBoundary`（`:39`）+ `ErrorPlaceholder` + `ErrorBoundaryElement` / `RenderErrorBoundary`：
  **节点级兜底**——一个控件坏了不拖垮整页。

## 9. 菜单 / 拖放 / 语义

- 菜单：`Menu`/`MenuBar`/`MenuItem`/`ContextMenu`（`src/Widget/Menu/`）—— **菜单是数据**，应用内自绘。
- 拖放：`Draggable`/`DragTarget`（`src/Widget/Drag/`）。
- 语义：`SemanticsBuilder`（`src/Widget/SemanticsBuilder.php:32`）：把声明了 `semantics()` 的控件收集成语义树。
