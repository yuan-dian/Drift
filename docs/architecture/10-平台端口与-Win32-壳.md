# 10 · 平台端口与 Win32 壳

## 1. 一句话

平台是**能力端口的集合**，不是上帝接口：`Platform`（`src/Platform/Platform.php:48`）聚合一组端口接口，
每个端口表达一个能力；Win32 是**唯一实现**（`Win32Platform`，`src/Platform/Win32/Win32Platform.php:46`）。
第二个平台只写壳 + 适配器，**框架零改动**。渲染表面有两条：`Win32RasterSurface`（纯 PHP 软光栅）与
`Win32SkiaSurface`（Skia），由 `SurfaceProvider` 选。壳侧负责三件框架外的致命契约：退出路径窗口已死
⇒ 缓存最后已知几何；拖动 resize 走同步泵 + 轻量重绘；IME 候选框锚定。

## 2. 端口接口（能力三态：支持 / 降级 / 不支持）

| 端口 | 接口文件 | 表达的能力 |
|---|---|---|
| 窗口 | `WindowHost`（`src/Platform/WindowHost.php:29`） | 创建/销毁窗口、消息泵、几何 |
| 渲染表面 | `RenderSurface`（`src/Rendering/RenderSurface.php:16`） | 把 `DisplayList` 上屏 |
| 表面选择 | `SurfaceProvider`（`src/Platform/SurfaceProvider.php:26`） | Raster vs Skia |
| 屏幕 | `Screen`（`src/Platform/Screen.php:22`） | DPI / 客户区 |
| 剪贴板 | `Clipboard`（`src/Platform/Clipboard.php:22`） | 复制粘贴 |
| 对话框 | `Dialog`（`src/Platform/Dialog.php:22`） | 文件对话框等 |
| 托盘 | `Tray`（`src/Platform/Tray.php:19`） | 托盘图标/退出 |
| 输入源 | `InputSource`（`src/Platform/InputSource.php:27`） | 原生消息 → `InputEvent` 归一化 |
| GPU（留口） | `GpuContext`（`src/Rendering/GpuContext.php:20`） | 接口已留，首版未实现 |

★ **没有定时器端口**：`after()` 是纯 PHP 的到期时刻（`PumpHost::nextDeadlineMs()`），
帧时钟把它换算成"等多久"交给 `waitEvents()`，由壳侧高精度可等待定时器落地。
曾经的 `TimerHost` 在消费者归零后删除 —— 它和帧时钟抢同一个唤醒源，两个闹钟只会更难协调。

## 3. 两种渲染表面

- `Win32RasterSurface`（`src/Platform/Win32/Win32RasterSurface.php:32`）：纯 PHP `RasterCanvas` 软光栅上屏。
- `Win32SkiaSurface`（`src/Platform/Win32/Win32SkiaSurface.php:35`）：真 Skia 后端（C++ 桥 `php_drift_skia_*`）。
- `Win32SurfaceProvider`（`src/Platform/Win32/Win32SurfaceProvider.php:21`）按能力/配置选其一。
- ★ 无论哪条后端，生产路径都先 `RecordingCanvas` 录制 `DisplayList` 再回放（[04](04-绘制与双后端.md) §5），
  所以两后端像素可比、可 golden。

## 4. 壳侧三件致命契约（框架外的硬边界）

1. **退出路径窗口已死**：`WM_CLOSE` 同步 `DestroyWindow` ⇒ 壳侧缓存最后已知几何，框架读窗口尺寸前先查缓存。
2. **拖动 resize**：模态尺寸循环里 PHP 主循环被挂起 ⇒ 壳在 `WM_SIZE` **同步**调
   `Application::repaintForResize()`（`src/App/Application.php`，只重绘不碰帧外物），拖动中禁拉伸、原尺寸贴 + 余区填底色。
3. **IME 候选框**：Win32 壳 + `TextInputClient` 协议；锚点走 `RenderBox::absoluteOrigin()`（[03](03-布局与渲染盒.md) §6）+ `Element::findBox()` 穿过包装层拿 `RenderTextField` 本身。

## 5. 输入归一化边界

Win32 把原生消息翻译成 Drift 的 `InputEvent`（`src/Input/InputEvent.php:31`），其余全走框架
（[06](06-输入-手势与焦点.md)）。合成鼠标移动必须真挪物理光标（探针 `--cursor`）。

## 6. 验证口径

```bash
# 端口接口全集
grep -rln "interface WindowHost\|interface RenderSurface\|interface SurfaceProvider\|interface Screen\|interface Clipboard\|interface Dialog\|interface Tray\|interface InputSource" src/Platform/

# Win32 是唯一的 Platform 实现
grep -rln "implements Platform" src/Platform/Win32/

# 两种 surface 都在
grep -rln "implements RenderSurface" src/Platform/Win32/

# 壳侧轻量重绘入口
grep -n "function repaintForResize" src/App/Application.php
```
