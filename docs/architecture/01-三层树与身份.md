# 01 · 三层树与身份

> 对应 design-v7 [03-树与身份](../design-v7/03-树与身份.md)。本文描述**实现**。

## 1. 一句话

Drift2 不是 Flutter 的三棵树，也不是 WPF 的双树——它是**一棵逻辑树同时承载三层语义**：
`Widget`（不可变配置）→ `Element`（身份 + State 宿主 + 调和）→ `RenderObject`/子类 `RenderBox`
（几何 + 绘制）。三层由同一棵树的三个基类表达，节点复用靠 `(type, key)` diff，身份由**位置 + Key**
决定，不在实例上存可变 UI 状态。

## 2. 三个基类

| 层 | 类 | 文件 | 职责 |
|---|---|---|---|
| 配置 | `abstract class Widget` | `src/Widget/Widget.php:25` | 纯描述。fluent-first 链式 API；`seal()` 封存；`createElement()` 是唯一造元素入口 |
| 身份/State | `abstract class Element` | `src/Widget/Element.php:19` | 持 `State`；`(type,key)` diff；帧末 `settle()` 脏重建；**不画、不算几何** |
| 几何/绘制 | `abstract class RenderObject` → `abstract class RenderBox` | `src/Layout/RenderObject.php:21`、`src/Layout/RenderBox.php:25` | `layout()` 算尺寸 + 定位子；`paint()` 绘制；`hitTest()` 命中 |

★ 注意 `Element` **住在 `src/Widget/` 而非独立的 `Element/`**：它是三树的"中间一棵"，归 Widget 层管。

## 3. 谁来造谁（单一入口，避免 45 个控件各抄一句）

- `Widget::createElement()`（`src/Widget/Widget.php:115`）是唯一造元素入口，内部用**一处**
  `instanceof StatefulWidget` 决定 `new StatefulElement` 还是 `new StatelessElement`——而不是让每个
  控件子类各写 `return new XxxElement`。理由：`Column::make()` 这类 45+ 控件抄同一句话，漏抄的不会报错，只会静默走错元素类型。
- `Element::syncBox()`（`src/Widget/Element.php:106`）是唯一的造/换渲染盒入口：Widget 是
  `RenderBoxWidget` 就调它的 `createRenderObject($ctx)`，否则盒为 `null`（纯结构节点）。
- `RenderBoxWidget`（`src/Widget/RenderBoxWidget.php:21`）是"有渲染盒的 Widget"的抽象基类；
  `Checkbox`/`Card`/`Text`/`SizedBox`/…都继承它。`StatelessWidget`/`StatefulWidget` 不继承它
  （它们常做组合描述，自己没盒，靠 `effectiveBox()` 往下找第一个有盒的后代）。

## 4. Seal-on-Mount（挂载即封存）

- `Widget::seal()`（`src/Widget/Widget.php:141`）把 `$sealed` 置 1。
- `Element::mount()`（`src/Widget/Element.php:68`）第一步就 `$this->widget->seal()`。
- 封存后任何链式修饰调 `mutate()`（`src/Widget/Widget.php:159`）⇒ `Errors::report(...)` 响亮失败（Fatal 级，release 也中止）。
- 后果：Widget 是不可变描述，刷新时**整体换新描述**（`Element::update()`，`src/Widget/Element.php:192`），不存在"字段级半同步"——GUI 仓"两份手写字段赋值 ⇒ 首次正常、刷新变样且静默"在结构上不可能。

## 5. 身份 = 位置 + Key

- 不给 Key ⇒ 身份由在 `children([...])` 里的**位置**决定；给了 ⇒ 重排也保得住 State（`Widget::key()`，`src/Widget/Widget.php:83`）。
- `ForEach`/列表的 Key **必填**（否则列表重排最需要它时反而丢身份）。
- 调和在 `Element::updateChildren()`（`src/Widget/Element.php:344`）：逐槽用
  `get_class($candidate->widget()) === get_class($newWidget) && Key::same(...)` 找可复用旧子；
  复用则 `update()`，否则 `unmount()` 旧的、`createElement()`+`mount()` 新的。

## 6. 帧末脏重建与挂接（静默坑的来源）

- `Element::settle()`（`src/Widget/Element.php:282`）每帧只重建标脏的 `StatefulElement`（`state()->needsBuild()`），然后后序 `adoptBoxes()`。
- ★★★ `adoptBoxes()` 必须后序、且子层重建换了盒后祖先必须重挂：漏掉就是**静默**的——脏的
  `StatefulElement` 重建后 `syncBox()` 造出新盒，但**祖先容器仍握着旧盒对象** ⇒ `layout()/paint()`
  走重建前的渲染树，画面纹丝不动、也不报错。首个暴露者：`TextField`（`src/Widget/TextField.php`）。
- `effectiveBox()`（`src/Widget/Element.php:129`）与 `findBox(callable)`（`src/Widget/Element.php:159`）
  的区别：前者是"父要挂接子盒"用的第一个盒（可能穿过包装层），后者是"指定控件的盒"必须穿过
  包装层继续找（IME 光标矩形用，否则有 label 的字段候选框贴左上角）。
