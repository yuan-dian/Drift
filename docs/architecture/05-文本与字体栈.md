# 05 · 文本与字体栈

## 1. 一句话

文本栈是**三拆**的：度量（`TextMetricsProvider`）/ 整形（`TextShaper`）/ 编辑（`TextField` 状态）
各管各的；度量**归 Drift 自己**（不外包给系统 API），所以无窗也能确定性出像素。字体走
`FontFace` 接口 + 回退链（TTF → 位图 → notdef），缺字有兜底；IME 走 `TextInputClient` 协议。

## 2. 三层接口与确定性实现

| 层 | 接口 | 确定性实现 | 文件 |
|---|---|---|---|
| 度量 | `TextMetricsProvider`（`src/Text/TextMetricsProvider.php`） | `DeterministicMetricsProvider`（`src/Text/DeterministicMetricsProvider.php`） | 同输入同输出，无窗可跑 ⇒ golden 可比 |
| 整形 | `TextShaper`（`src/Text/TextShaper.php`） | `DeterministicShaper`（`src/Text/DeterministicShaper.php`） | 字形归属/定位 |
| 字体集合 | `FontCollection`（`src/Text/FontCollection.php`） | `DeterministicFontCollection`（`src/Text/DeterministicFontCollection.php`） | 回退链 |
| 字体管理 | `FontManager`（`src/Text/FontManager.php`） | `DeterministicFontManager`（`src/Text/DeterministicFontManager.php`）、`FontLocator`（`src/Text/FontLocator.php`） | 定位/加载 |
| 字体面 | `FontFace`（`src/Text/FontFace.php`） | `TtfFace`、`BitmapFontFace`、`NotdefFontFace` | TTF / 位图 / 缺字兜底 |

★ `TextLayout`（`src/Text/TextLayout.php`）把"文本+样式+最大宽+缩放"排成 `Paragraph`
（`TextLayout::layout()` 与 `TextMetricsProvider::layout()` 同签名）。字形位图在**回放时**才产生
（`Canvas::drawParagraph` 存 `Paragraph` 引用，见 [04](04-绘制与双后端.md) §2），录制代价与字形数无关。

## 3. 为什么度量归 Drift

design-v7 的硬理由在本实现落地：系统文本 API 在无窗/跨平台下不可复现，golden 需要"同输入同像素"。
所以度量层是**确定性**的（`Deterministic*`），不依赖 GDI/DirectWrite 的当机行为。

## 4. 字体回退链与缺字

`DeterministicFontCollection` 按 `FontFace` 顺序回退；`NotdefFontFace` 是链尾兜底（缺字不崩，画占位）。
CJK 与拉丁分别有预置字形数据：`CjkGlyphData`（`src/Text/CjkGlyphData.php`）、
`LatinGlyphData`（`src/Text/LatinGlyphData.php`）、`DeterministicFontData`。

## 5. 编辑与 IME

- `Text`（`src/Widget/Text.php`）是纯展示；`TextField`（`src/Widget/TextField.php`）+ `TextFieldBox`
  + `TextFieldState`（`src/Widget/TextFieldState.php`）是可编辑。
- IME 协议：`TextInputClient` 接口（`src/Text/TextInputClient.php`）。候选框锚点走
  `RenderBox::absoluteOrigin()`（[03](03-布局与渲染盒.md) §6）+ `Element::findBox()` 穿过包装层
  拿 `RenderTextField` 本身（否则有 label 的字段候选框贴左上角）。
- 选区：多行纯文本 + 选区（首版非富文本）。

```bash
# Paragraph 在回放时才产生字形位图
grep -n "drawParagraph\|Paragraph" src/Rendering/Canvas.php | head

# IME 协议
grep -n "interface TextInputClient" src/Text/TextInputClient.php
```
