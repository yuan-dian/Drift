## 1. 一句话

工具链全 PHP 单语言；`project.yml` 描述 `sources`，tpc（PHP→C++17）出两种产物：
**生产态**全静态 AOT exe、**开发态**只编「壳 + C++ 桥」的 `dev.exe`。
验证按**运行形态**分层（§3），不按脚本名分层 —— 同一个 `probe-window.py`
用五条判据跑三种形态，才是「换运行形态不换判据」。

## 2. 构建形态

- `project.yml`：`sources` 覆盖的命名空间须与 `composer.json` 的 `autoload.psr-4`
  一致（`scan-autoload-drift` 守）；不一致的症状是「preview 能跑、AOT 编译不过」。
- 生产：`php tools/drift-build.php <app>`。三态由 `Drift\Dev\Build\StalePolicy` 裁决
  （见 `DESIGN.md` §16.2.2）：输入未变且产物仍在 ⇒ **跳过编译**（仍分发运行时
  `php.ini` 与 TLS 信任根）；输入变了 / 首次 / 产物不在 ⇒ **自动全量**，清根 `build/`
  与 app 级 `build/`（门不能信缓存，与 T1 `drift-codegen` 同口径）；只有
  `--incremental` 显式 opt-in 才走增量（可能 stale）。`--full` 强制全量；`--dry`
  只打印这次决策，不构建、不清缓存。输入清单按应用分文件落 `_build/`，互不干扰。
- 开发：`php tools/drift-dev.php [应用名]`。壳输入（cpp-src / 壳配置 / 两个桥接回调
  文件）不变就永不重编；业务 PHP 改动只重启窗口。红线、已知边界与实测见
  [`DEV-MODE-2026-11-05.md`](../DEV-MODE-2026-11-05.md)。
- ★ 出哪个 exe 才编哪个 app；dev 壳只编一次，所有应用共用。

## 3. 三层验证（按运行形态）

| 层 | 入口 | 覆盖 | 何时跑 |
|---|---|---|---|
| **T0 无头** | `php tools/gate.php` | lint 架构门禁 / 单测 / 场景 / golden 像素 / smoke / **dev 壳红线**；无 OS 窗口、可 CI、确定性 | 每次提交（`--fast` 跳慢项） |
| **T1 dev 真机** | `php tools/drift-dev.php <app>`<br>`python tools/probe-window.py <app> --dev` | 真窗口、真 C++ 桥、真 DPI / 像素 / 关窗退出码；改 PHP 秒级生效 | 每次改业务 PHP |
| **T2 AOT 真机** | `php tools/drift-build.php <app>`<br>`python tools/probe-window.py <app>` | **唯一**能抓 AOT 编译期问题 | 发版前一次；碰了 §3.1 清单必须跑 |

`--dev-runner` 是 T1 的第三种形态（跑完整 `drift-dev.php` 而不是直接起 `dev.exe`），
用于验证运行器自身的启动 / 环境拼装；`DRIFT_PROBE_*` 三个环境变量留给自定义形态。

**T2 的逐值等价量具**（都要编译产物、都不进 gate，见
[`DEV-MODE-2026-11-05.md`](../DEV-MODE-2026-11-05.md) §8）：
`php tools/aot-equivalence.php`（解释器↔AOT）与
`php tools/dual-mode-equivalence.php`（解释器↔dev 壳）。两者共用同一份
`Fingerprint::snapshot()` 作**唯一 expected**，不建第二套基线。

**T0 与 T1 都不编译业务 PHP ⇒ 都看不见 AOT 编译期语义。** dev 壳把「编译」从每次改
代码里挪走，不是把 AOT 验证删掉。以前每棒跑一次全 AOT 重建，现在降到发版前一次；
省下的是时间，少掉的正是那层盲区的日常提醒，所以 §3.1 的清单必须显式保留。

### 3.1 dev 绿 ≠ AOT 绿（这些改动必须 T2）

- 控制流 `switch`、两支类型不同的 `?:`、属性读直接当实参 ⇒ C2440 / C2678 / C2872
  （[11](11-编译器约束与-AOT-坑.md)）。解释器面和 dev 面全绿，只有 T2 炸。
- `int / int` 被 tpc 编成整数除法（静默截断）；逐值比对靠
  `php tools/aot-equivalence.php` + `php tools/fingerprint.php`，它们跑的是同一份
  `Fingerprint`，一侧解释器、一侧 AOT 产物。
- 编译期常量（`__DIR__` 等）、Trait / 编译期注解的可见性、`sources` 与
  `composer.json` 的命名空间扫描。
- AOT 侧析构与 shutdown：组合根对象图释放曾崩在 `php8ts.dll`。判据 ⑤ 在 dev 态过，
  不代表编译后的析构路径也过。
- 扩展加载与 `php.ini` 分发（dev 用运行器自己生成的临时 ini）。

⇒ 碰了任一类，dev 全绿也**必须**跑 T2。逐值判据现在有两条（各守一路、共用
同一份 `Fingerprint`）：`aot-equivalence.php` 守 AOT、`dual-mode-equivalence.php`
守 dev 壳。日常不碰 AOT 之后它们反而更重要 —— 别因为它们要编译产物就删。

### 3.2 不因 dev 壳而删除的手段（覆盖面互不重叠）

| 手段 | dev 壳替不了什么 |
|---|---|
| `gate.php` 全项 | 无头、确定性、CI 可跑；dev 壳要真 OS 窗口 |
| `drift-preview.php` / `probe-raster-page.php` | 无 OS、跨平台、SVG / PNG 可 diff；同一条渲染路径但不是真窗口 |
| golden 原语与整页 | 像素级确定性基线；真窗口受 DPI / 时序影响，不能当基线 |
| `aot-equivalence.php` + `fingerprint.php` | 唯一能发现 AOT / VM 语义差异（全 AOT 那一侧） |
| `dual-mode-equivalence.php` | 唯一能验「dev 壳 ZendVM 动态加载」与解释器逐值一致；与上一行是两路不同形态 |
| `probe-real.php` + `probe-grab.exe` | 按身份定位 + 真输入 + 真像素；`--dev` 只量首屏 |
| `probe-window.py` 判据 ④⑤ | DPI V2 与 shutdown 退出码在 T1/T2 各测一遍，语义不同 |

已删除：`tools/probe-showcase.php`（手量坐标、`exec` 起 GUI、`proc_close` 等窗口消失）
—— 功能由 `probe-real.php` 与 `probe-window.py` 覆盖，且后者统一走
`App.close()` 自动关窗。历史提及见 `arch-v2/09` 的原段与订正。

## 4. 量具

- `SurfaceProfile`（`src/Rendering/SurfaceProfile.php:22`）：帧内分段计时开关（pumpIo/
  pumpTasks/anim/placeOverlays/focus/semantics 等段键），定位「慢在哪个阶段 + 节点」。
- `FrameStats`：帧成本聚合。
- 真机探针：`tools/probe-grab.cc`（C++，抓真窗口像素；`--cursor` 真挪物理光标、
  `--mdrag` 每步 `SetCursorPos`）；`_build/scan_col.php` + `_build/p4-crop.php` 量盒矩形；
  `_build/pnglook.php` + `_build/p4-assert.php` 按色找 bbox / 非白直方图。

## 5. 应用

`apps/` 下每个目录一个工程，另加 `apps/dev/`（开发态壳，不是应用）。常见角色：

| 目录 | 角色 |
|---|---|
| `hello` | 最小可运行窗口 |
| `showcase` | 能力示例集（页面会随能力增长，别在文档里写死数量） |
| `users` | 完整应用：列表 / 搜索 / 表单 / 异步 / 菜单 / 快捷键 |
| `tutorial` | 配套 `docs/tutorial.md` 的教学工程 |
| `bench` / `pacing` / `watermark` | 性能基准 / 帧节奏 / 真实 HTTPS 与外部 IO |
| `dev` | AOT 壳，仅供 `drift-dev.php` 使用 |

## 6. 验证口径

```bash
php tools/gate.php                                  # T0 全项
php tools/drift-dev.php showcase                     # T1 开发态（改 PHP 自动重启）
python tools/probe-window.py showcase --dev         # T1 五条判据 + 自动关窗
php tools/drift-build.php showcase                  # T2 编译（输入未变则短路）
python tools/probe-window.py showcase               # T2 同五条判据，跑全 AOT 产物
```

★ 起窗口的验证脚本**一律自己关窗**（`probe_win.App.close()`：先 `WM_CLOSE`，超时按
进程树强杀）。不要用 `proc_close` 等窗口消失 —— 那会把收尾甩给人，还会污染
「关窗后退出码 0」判据。
