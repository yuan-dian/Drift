# 12 · 工程与工具

> 对应 design-v7 [12-工程与工具](../design-v7/12-工程与工具.md)。本文描述**实现**。

## 1. 一句话

工具链全 PHP 单语言、单一入口；AOT 用 `project.yml` 描述 + tpc 编译器（PHP→C++17）出 exe。
验证分四层：lint（架构门禁）→ smoke（解释器面 900+ 探针）→ golden（录制-回放像素比对）→
T2 真机构建（唯一的 AOT 真相源）。四个 app：`hello` / `bench` / `showcase` / `users`。

## 2. 构建形态

- `project.yml`：描述 `sources`（覆盖的命名空间 == `composer.json` 的 `autoload.psr-4`，由
  `scan-autoload-drift` 守——不一致的症状是"preview 能跑、AOT 编译不过"）。
- tpc（`bin/tpc.php`）：共享 base，已验证可构建；`-O2 -m bin/lib` 两种产物（应用 exe / 库）。
- ★ **只建一个 app**：框架在每个应用里编译方式相同，建第二个纯属浪费（`--build showcase` 只在确实要出那个 exe 时才跑）。

## 3. 四层验证（开发内环）

| 层 | 入口 | 作用 | 耗时档 |
|---|---|---|---|
| lint | `php tools/lint.php --list` | 架构门禁（依赖规则、死订阅、死命令、G2 等） | 秒级 |
| 预览 | `preview --svg` | 无窗渲染一帧 | 秒级 |
| smoke | `tools/smoke.php` | 解释器面 900+ 探针（`--fast` ~1.5s 跑完整 `Application::run()`） | ~15s（T1） |
| golden | `RecordingCanvas` 录制 + 回放比对 | 像素级确定性 | — |
| T2 真机构建 | `--build` + `--selectest` + `report.sh` | **唯一能抓 AOT 专属问题（C2440/C2678/C2872）** | ~4–5min |

★ 分级（用户裁决）：T0 示例/文档只 `php -l`+预览；T1 核心改动迭代用 `--lint`+`--fast demo`；
T2 提交/发版前一次（抓 AOT 专属）。**T1 抓不到 AOT 专属问题** ⇒ 碰了 `switch`/`?:`/闭包/多字节堆损坏
模式的改动必须 T2（[11](11-编译器约束与-AOT-坑.md)）。

## 4. 量具

- `SurfaceProfile`（`src/Rendering/SurfaceProfile.php:22`）：帧内分段计时开关（pumpIo/pumpTasks/
  anim/placeOverlays/focus/semantics 等段键），定位"慢在哪个阶段 + 节点"。
- `FrameStats`：帧成本聚合。
- 真机探针：`tools/probe-grab.cc`（C++，抓真窗口像素；`--cursor` 真挪物理光标、`--mdrag` 每步
  `SetCursorPos`）；`_build/scan_col.php` + `_build/p4-crop.php` 量盒矩形；`_build/pnglook.php` +
  `_build/p4-assert.php` 按色找 bbox / 非白直方图。

## 5. 四个 app

| app | 角色 | 说明 |
|---|---|---|
| `apps/hello` | 最小可运行 | 一个窗口画 "Hello Drift" |
| `apps/bench` | 性能基准 | 虚拟化万行列表实测 96ms→0.2ms；M4 端到端 9.2ms→3.1ms（阶段 0/26 实测） |
| `apps/showcase` | 能力示例集 | 9 个页面（含动画 Motion 页），演示控件/动画/主题 |
| `apps/users` | 完整应用 | 列表 + 搜索 + 删除 + 表单 + 异步 + 多页 + 菜单 + 快捷键（[07](07-状态-订阅-命令.md) 的命令链范本） |

## 6. 验证口径

```bash
# 工具入口
ls tools/ | grep -E "smoke|autoload|lint"
ls apps/

# 构建描述
find . -maxdepth 2 -name "project.yml" | head

# smoke 探针数量（解释器面）
grep -c "check(" tools/smoke.php
```
